Conencted a Raspberry Pi 4 Model B 4GB to a GE B650 monitor (software version 2?).
Used 2 ATEN UC232A-USB connectors via a F/F null-modem adapter.
The UC232A-USB connector on the montior side needs a serial number below Z3L1.
This document describes the setup and recording for an offline Pi. Pi is accessived via hotspot wifi by my laptop to extract recordings periodically.
